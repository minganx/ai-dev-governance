# Context7 安装说明

Context7 由 Cursor、Codex 和 Claude Code 分别安装和管理，本仓库不统一写入配置、保存 API Key 或执行安装、更新、检查和卸载。设备安装器在安装和更新时只输出一次官方安装文档链接。

按 [Context7 官方客户端安装文档](https://context7.com/docs/resources/all-clients)选择对应 Agent 的章节：

| Agent | 安装文档 |
| --- | --- |
| Cursor | 官方文档中的 Cursor 章节 |
| Codex | 官方文档中的 Codex 章节 |
| Claude Code | 官方文档中的 Claude Code 章节 |

各 Agent 的配置入口和安装方式不同，以对应章节的最新说明为准。凭据只保存在所用工具支持的本地配置或凭据存储中，不提交到本仓库。

历史安装留下的 Context7 配置、本地启动器和密钥保持原样，不会被本仓库的更新或卸载修改。迁移后是否清理这些文件由使用者决定。
